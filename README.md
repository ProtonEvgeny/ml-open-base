# ML Open Base

Открытая база знаний по машинному обучению и искусственному интеллекту — для людей и агентов.

## О проекте

ML Open Base — это открытая и обширная база знаний по ML и AI. Она объединяет теоретические материалы и практические руководства, а публикуется в формате удобной веб-документации.

Проект одинаково ориентирован на людей и на агентов: материалы должны быть понятны читателю и при этом хорошо извлекаться и использоваться автоматизированными инструментами.

Проект распространяется под лицензией MIT.

## Статус

Проект находится в ранней стадии разработки. Структура разделов и наполнение ещё формируются, поэтому часть материалов может отсутствовать или меняться.

## Стек

- [Blume](https://useblume.dev) 2.x — фреймворк документации на базе Astro и Vite.
- Node.js >= 22.19.0 — версия закреплена в `.nvmrc`.
- npm — зависимости фиксируются через `package-lock.json`.

## Быстрый старт

Убедитесь, что установлен Node.js >= 22.19.0. Если используется nvm:

```bash
git clone https://github.com/ProtonEvgeny/ml-open-base.git
cd ml-open-base
nvm use
npm install
npm run dev
```

Дев-сервер запустится с горячей перезагрузкой.

| Команда           | Назначение                              |
| ----------------- | --------------------------------------- |
| `npm run dev`     | Запустить дев-сервер                    |
| `npm run build`   | Собрать статический сайт в `dist/`      |
| `npm run doctor`  | Проверить конфигурацию и контент        |

`dev` и `build` предварительно проверяют версию Node и завершаются ошибкой, если она ниже требуемой.

## Структура репозитория

| Путь               | Назначение                                            |
| ------------------ | ----------------------------------------------------- |
| `docs/`            | Контент: файлы становятся страницами и пунктами меню  |
| `blume.config.ts`  | Конфигурация сайта                                    |
| `scripts/`         | Вспомогательные скрипты                               |
| `.blume/`, `dist/` | Сгенерированные файлы — не редактируются и не коммитятся |
| `node_modules/`    | Зависимости                                           |

## Участие

Мы рады исправлениям, переводам и новым материалам. Работа идёт через ветки и pull request: прямые пуши в `main` закрыты, включая мейнтейнеров.

Правила именования веток и коммитов, требования к PR и порядок ревью — в [CONTRIBUTING.md](CONTRIBUTING.md). Дополнительные ограничения для агентов — в [AGENTS.md](AGENTS.md).

## Языки

Сайт двуязычный: `ru` — язык по умолчанию, `en` — второй язык. Материалы на языке по умолчанию находятся в корне `docs/`, переводы — в `docs/en/`. Переводы могут отставать от оригиналов.
