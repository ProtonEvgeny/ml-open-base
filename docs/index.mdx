**ML Open Base** — это открытая база знаний по машинному обучению (ML) и искусственному интеллекту (AI). Здесь собраны статьи, которые объясняют ключевые понятия ML/AI простым техническим языком — с формулами, примерами и разбором интуиции за каждой концепцией.

## Зачем этот проект

Материалов по ML/AI очень много, но они сильно разбросаны: что-то есть в документации библиотек, что-то в научных статьях, что-то в блогах. Часто одна и та же тема объясняется либо слишком поверхностно, либо, наоборот, излишне академично.

ML Open Base решает эту проблему: **собирает в одном месте структурированные, понятные и практичные объяснения**.

## Для кого

- Для тех, кто **начинает изучать ML/AI** и хочет разобраться в базовых понятиях.
- Для **практикующих инженеров**, которым нужно быстро освежить тему или найти точную формулу.
- Для всех, кто хочет **понимать, а не заучивать** — каждая статья старается дать интуицию, а не только определение.

## Принципы

- **Просто, но не примитивно.** Упрощённый технический язык, без лишних оборотов, но с сохранением корректности.
- **Примеры обязательны.** Один-два небольших примера помогают лучше понять абстрактное определение.
- **Открытость.** Материалы можно читать, использовать, распространять и предлагать изменения.
